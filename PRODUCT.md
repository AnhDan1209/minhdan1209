# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Fans of Cristiano Ronaldo who want to learn about his biography and achievements and play the site's mini-game.

## Product Purpose

Help visitors learn about Cristiano Ronaldo and enjoy interactive experiences in one Vietnamese-language website. Success means visitors can explore the existing profile, career information, achievements, and records, then engage with the quiz or penalty mini-game.

## Positioning

A Vietnamese CR7 fan site that combines an editorial profile and career highlights with a quiz and an interactive penalty challenge.

## Operating Context

- The site is accessed as a web experience on desktop and mobile-sized screens.
- `index.html` contains the main CR7 profile, career information, achievements, records, and quiz.
- `game.html` contains the penalty mini-game.

## Capabilities and Constraints

- The existing project uses static HTML, CSS, and JavaScript, with Tailwind CSS loaded from a CDN.
- Existing navigation, quiz behavior, game controls and scoring, and theme switching are part of the product.
- Keep factual claims about Ronaldo grounded in the project's existing content or a source supplied by the user; do not invent new statistics, awards, dates, or quotes.
- Preserve current behavior when changing presentation unless the user explicitly requests a functional change.

## Brand Commitments

- The site is centered on CR7 and uses Vietnamese copy.
- Preserve the current dark black-and-gold theme and light white-and-orange theme.

## Evidence on Hand

- Existing project files: `index.html`, `game.html`, `style.css`, and `script.js`.
- Existing visual and media assets are in the `image/` and `sound/` folders.
- Treat the site's current copy and assets as project evidence; verify any new factual claim before adding it.

## Product Principles

- Make learning about CR7 clear and engaging.
- Keep the quiz and mini-game enjoyable without compromising their existing behavior.
- Improve presentation while preserving the content and features fans already use.
