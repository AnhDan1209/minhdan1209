# Project guidance

## Product context

- This is a Vietnamese-language Cristiano Ronaldo fan site with a profile, career timeline, trophies, records, quiz, and a penalty mini-game.
- The main pages are `index.html` and `game.html`; styling is in `style.css`, and page behavior/data are in `script.js` plus inline page scripts.
- The project is a static HTML/CSS/JavaScript site. It currently uses Tailwind through its CDN, Font Awesome, and Google Fonts. Keep the existing lightweight setup unless the user asks to change it.

## Product and content constraints

- Keep the Vietnamese copy and CR7 subject clear and respectful.
- Preserve existing content, navigation, theme switching, quiz behavior, scoring, and game controls unless the user asks to change them.
- Do not invent Ronaldo statistics, awards, dates, quotes, endorsements, or other factual claims. Use the project’s existing content or ask for a source when new factual content is needed.
- Retain the existing dark black-and-gold theme and light white-and-orange theme as the site's current identity. Extend their CSS variables and tokens instead of creating a parallel color system.

## UI work

- For interface design or refinement, use UI/UX Pro Max for relevant layout, typography, color, accessibility, responsive, and stack guidance; use Impeccable to refine and review the result.
- Start by inspecting the affected page and existing styles/scripts. Make the smallest coherent change that meets the request, and keep the site's established identity unless the user requests a redesign.
- Check the affected page at desktop and mobile widths, and confirm that visible controls still work after UI changes.
- Avoid adding dependencies or changing the project structure for a visual-only request.
